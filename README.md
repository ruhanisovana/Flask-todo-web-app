# Flask Todo Web Application

## Overview

A simple and clean Todo application built with Flask to help users manage daily tasks efficiently.

---

## Problem

People often forget important daily tasks because they are scattered across notes and messaging apps.

---

## Solution

A lightweight task management application where users can create, update, complete, and delete tasks.

---

## Features

- Add Tasks
- Delete Tasks
- Update Tasks
- Mark Completed
- Responsive Interface

---

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
